# 5 ночей на хате у Олега

3D-игра в браузере: подарок Олегу на днюху. Ты Олег, пацаны пришли бухать. Твоя задача — продержаться до 06:00, чтобы общее веселье не упало до нуля, хата уцелела, а кот не выпал с балкона.

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173. Играть нужно с компа.

Онлайн: https://depthd.github.io/bebebe/ (собирается и выкладывается сама при пуше в основную ветку).

| Клавиши | Что делают |
|---|---|
| WASD, Shift | ходить, бегом |
| мышь | смотреть |
| E / R / T | действие с тем, на что смотришь |
| 1–4, колесо | слот инвентаря |
| Q | выпить или съесть самому |
| G | выбросить предмет |
| F | телефон: камера у двери и доставка |
| Esc | пауза |

Концепт и механики описаны в [docs/CONCEPT.md](docs/CONCEPT.md), все числа баланса — в `src/config.js`. План квартиры рисует `npm run plan` (в `docs/plan.svg`).
